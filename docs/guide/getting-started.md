# 开始使用

欢迎使用 Nova UI！

## 安装

```bash
npm install @nova-kits/components
# 或
yarn add @nova-kits/components
# 或
pnpm add @nova-kits/components
```

## 使用

```vue
&lt;script setup lang="ts"&gt; import { Popup } from '@nova-kits/components'; &lt;/script&gt;
&lt;template&gt; &lt;Popup /&gt; &lt;/template&gt;
```
